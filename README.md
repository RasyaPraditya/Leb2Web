# Leb2Web

1.	Fungsi elemen tabel HTML: 
o	<table>: Digunakan untuk membuat struktur tabel. 
o	<tr>: Digunakan untuk membuat baris pada tabel (table row). 
o	<th>: Digunakan untuk membuat sel header atau judul kolom/baris (table header). 
o	<td>: Digunakan untuk membuat sel data biasa (table data). 
2.	Perbedaan <th> dan <td>:
o	<th> digunakan untuk mendefinisikan sel sebagai header (kepala/judul) tabel, di mana teks di dalamnya secara default ditampilkan tebal (bold) dan berada di tengah (center). 
o	<td> digunakan untuk mendefinisikan sel sebagai data/isi tabel biasa, di mana teks di dalamnya ditampilkan secara normal dan rata kiri secara default. 
3.	Fungsi colspan pada tabel:
o	colspan berfungsi untuk menggabungkan dua atau lebih kolom dalam satu sel tabel secara horizontal. 
4.	Fungsi <form> dalam HTML:
o	Elemen <form> digunakan untuk menerima input dari pengguna (seperti teks, pilihan, file, dll.) dan mengirimkan data tersebut ke server.
5.	Perbedaan radio button dan checkbox:
o	Radio Button (<input type="radio">): Hanya memungkinkan pengguna memilih satu pilihan dari serangkaian opsi yang tersedia.
o	Checkbox (<input type="checkbox">): Memungkinkan pengguna memilih satu atau beberapa pilihan sekaligus.
6.	Alasan <label> sebaiknya terhubung dengan id input melalui atribut for:
o	Menghubungkan <label> dengan atribut for ke id elemen input meningkatkan aksesibilitas dan kemudahan pengguna. Pengguna dapat mengklik teks pada label untuk langsung memfokuskan atau mengaktifkan elemen input yang terhubung (misalnya menandai radio button atau checkbox).
7.	Perbedaan <textarea> dengan <input type="text">:
o	<input type="text">: Digunakan untuk menerima input teks singkat dalam satu baris (single-line).
o	<textarea>: Digunakan untuk menerima input teks yang lebih panjang dan mencakup banyak baris (multi-line), serta ukurannya (baris dan kolom) dapat diatur.
8.	Fungsi elemen semantic HTML:
o	<header>: Menandai bagian kepala dari halaman atau bagian (section).
o	<nav>: Berisi tautan navigasi utama.
o	<main>: Memuat konten utama yang unik dari halaman web.
o	<section>: Mengelompokkan konten yang berkaitan dalam satu topik.
o	<article>: Memuat konten mandiri yang dapat berdiri sendiri (seperti postingan blog atau berita).
o	<aside>: Berisi konten pelengkap atau informasi sampingan yang berhubungan dengan konten di sekitarnya.
o	<footer>: Menandai bagian kaki (bawah) dari halaman atau bagian (section).
9.	Fungsi atribut validasi dasar:
o	required: Menandakan bahwa bidang/input wajib diisi sebelum form dikirim.
o	min: Menentukan nilai angka/tanggal minimum yang diizinkan pada input.
o	max: Menentukan nilai angka/tanggal maksimum yang diizinkan pada input.
o	minlength: Menentukan jumlah karakter (panjang) minimum teks yang harus dimasukkan.
10.	Perbedaan elemen <audio> dan <video>:
o	<audio>: Digunakan khusus untuk memutar file suara/audio pada halaman web.
o	<video>: Digunakan untuk memutar file video (visual beserta suara) dan dapat dikustomisasi ukurannya (seperti width dan height).
